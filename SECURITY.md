# Security

Please do not report security issues in a public issue.

Open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainers see the report.

Please test only on [the demo](https://demo.unifiedsofthub.com/) and inside your own demo copy. Do not try to reach other visitors' copies, the server or any other system, and do not run automated scans or load tests.

## الأمان

لا تُبلّغ عن الثغرات الأمنية في بلاغ عام. افتح تبويب **Security** في هذا المستودع واختر **Report a vulnerability**، ولن يرى البلاغ إلا القائمون على المستودع.

اقتصر في الاختبار على [النسخة التجريبية](https://demo.unifiedsofthub.com/) وداخل نسختك الخاصة، ولا تحاول الوصول إلى نسخ الزوار الآخرين أو السيرفر أو أي نظام آخر، ولا تُشغّل فحوصات آلية أو اختبارات ضغط.
